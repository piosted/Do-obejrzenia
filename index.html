Konfiguracja

Podaj klucz API Google i ID playlisty. Zapisują się tylko na tym telefonie.

Google Cloud → API i usługi → Dane logowania → Klucz API.
Możesz też wkleić tutaj link konfiguracyjny z drugiego urządzenia — wypełni oba pola.
Możesz wkleić cały link — sam wyciągnę list=. Playlista musi być niepubliczna lub publiczna.
Otwieraj filmy w Brave Wyłącz, jeśli wolisz Safari / aplikację YouTube.
Otwórz ten link na drugim urządzeniu — ustawienia przeniosą się same, bez przepisywania klucza. Traktuj go jak hasło.
